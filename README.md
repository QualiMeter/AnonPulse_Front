# AnonPulse Frontend

Приложение на React, TypeScript и Vite. Кабинет преподавателя, конструктор, управление опросом, статистика, решение и публичное голосование подключены к Railway API через same-origin `/api`. Демонстрационные данные сохранены отдельно в `src/data/` и `src/features/publicVoting/demo*.ts`, но действующие маршруты их не используют и не подменяют ими ошибки сервера.

```bash
npm install
npm run dev
```

Локальный адрес: `http://localhost:5173/`. Для проверки cookie используйте именно `localhost`. Vite проксирует `/api` в Railway; браузер посылает `credentials: "include"`, а авторизация хранится только в защищённой HttpOnly cookie. Логин и пароль не сохраняются в исходном коде или браузерном хранилище.

## Маршруты

- `/login` — вход преподавателя; `/app/polls` — список его опросов.
- `/app/polls/new` — создание; `/app/polls/:id` — карточка; `/app/polls/:id/edit` — полная замена содержимого черновика.
- `/app/polls/:id/results` — промежуточные результаты владельца открытого опроса или итоговые результаты закрытого; решение доступно только после закрытия.
- `/p/:id` — публичное голосование без входа; `/p/:id/results` — публичные итоги только после закрытия.

Создание, изменение, публикация, закрытие, голосование и публикация решения отправляют реальные запросы в Railway и меняют данные на сервере. Используйте отдельные тестовые опросы для проверки. Голосование требует предварительного публичного GET, cookie и заголовка `X-AnonPulse-Vote: 1`; успех подтверждается только ответом `204 No Content`. При `409` публичного GET приложение проверяет наличие итоговых результатов и не делает вывод о закрытии по одному коду ошибки.

Публичные итоги сервер возвращает без названия опроса, поэтому страница `/p/:id/results`, открытая напрямую, показывает нейтральный заголовок «Итоги опроса». Для Vercel same-origin rewrite описан в `vercel.json`; перед production-развёртыванием нужно проверить передачу обеих cookie и заголовка голосования через HTTPS-прокси. Развёртывание фронтенда здесь не выполняется.

Локальный OpenAPI — снимок контракта. Фактическое поведение сверяйте с [текущим backend](https://github.com/QualiMeter/AnonPulse_Beckend) и `docs/api/Backend_Guide.md`.

Проверка сборки: `npm run build`.
