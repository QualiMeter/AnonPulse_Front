# AnonPulse Frontend

Визуальная версия интерфейса преподавателя на React, TypeScript и Vite.

```bash
npm install
npm run dev
```

Локальный адрес по умолчанию: `http://127.0.0.1:5173/`.

Сейчас доступны кабинет со списком опросов, карточка опроса, результаты, конструктор, публичное голосование и публичные итоговые результаты. Поиск, фильтры и переходы работают локально. Конструктор позволяет составить новый опрос или изменить демонстрационный черновик: управлять вопросами и вариантами, менять порядок вопросов, проверять форму и открывать предпросмотр. При уходе со страницы с изменениями появляется предупреждение.

Публичный маршрут: `/p/:id`. Пример открытого опроса: [`/p/61b0c86e-98f0-4978-a948-a82064f55f71`](http://127.0.0.1:5173/p/61b0c86e-98f0-4978-a948-a82064f55f71). Демонстрационные состояния загрузки, ошибок и повторного участия доступны через переключатель внизу страницы. Они не являются ответами сервера.

Публичные итоги доступны на `/p/:id/results` только для демонстрационных закрытых опросов. [Пример с решением](http://127.0.0.1:5173/p/a8ad6d3b-50bc-465d-9cd0-f77a2dd73051/results) и [пример без решения и участников](http://127.0.0.1:5173/p/db7d14c2-32dc-45d6-8c79-91df146d348a/results). Открытый опрос не показывает студенту промежуточную статистику. Страница закрытого опроса ведёт к итогам лишь при наличии отдельной демонстрационной записи итогов, а не по одному статусу публичного GET.

На странице статистики закрытого опроса преподаватель может открыть редактор решения. Текст должен содержать от 1 до 5000 символов. Публикация и обновление меняют только локальное состояние текущей вкладки, показывают подтверждение и сразу отражаются на публичной странице итогов при переходе внутри приложения. Перезагрузка возвращает исходные демонстрационные данные. Для черновика и открытого опроса редактор недоступен.

Данные преподавательских страниц находятся в `src/data/demoPolls.ts`, публичных опросов — в `src/features/publicVoting/demoPublicPolls.ts`, публичных итогов — в `src/features/publicVoting/demoPublicResults.ts`. Они служат только для оценки интерфейса. Форма конструктора, ответы студента и правки решения хранятся лишь в состоянии React. Сохранение черновика отключено; отправка голоса симулируется и ничего не записывает. Запросов к API нет; реальная публикация, закрытие, статистика и решение преподавателя ещё не подключены.

`docs/api/openapi.pending.json` описывает планируемый контракт, ещё не подтверждённый на работающем сервере. Файла `docs/api/v3.json` в проекте пока нет. Перед интеграцией нужно сверить текущий backend с контрактом и разрешить расхождения с более ранними документами. В частности, нынешний интерфейс следует актуальному правилу: студенты видят статистику только после закрытия, а решение можно публиковать и менять только для закрытого опроса.

Проверка сборки: `npm run build`.
